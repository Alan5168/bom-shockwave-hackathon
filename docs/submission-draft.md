## 官方信息表

### 作品名

断料雷达 · BOM Shockwave

### 一句话介绍

一颗电阻缺货，30 秒看清它会打停哪些产品、产线和客户单，以及该给每个部门发什么指令。

### 作品描述

中小工厂遇到缺料时，选项并不神秘：催交期、挪料保单、改客户承诺、找替代料、挤良率。
真正耗时的是先回答“这颗料到底会打到哪里、几号断线、每个选项还剩几天”。

断料雷达由一位前上市公司经营操盘手基于真实制造业工作模式设计。它把多层 BOM、库存、
到货计划和产线周计划放进一个浏览器本地运行的推演器：

- 递归展开 where-used，做缺料净算与到货批次分配；
- 把影响传播到成品、工单、产线、客户和延期成本；
- 改一个到货日期，冲击图、完工 delta 和行动排序即时重算；
- 将五类通用动作参数化：需要催回几天、该挪料保谁、滑单代价多少、替代料验证是否赶得上；
- 输出采购、产线、仓库、计划四张可复制工单，同时提供自然语言 prompt 与结构化 JSON。

它不靠 LLM 猜数字。所有数量、日期、净缺口、延期与排序由 TypeScript 确定性规则计算；
指令只由模板消费已算出的参数。运行时零 LLM、零 API key、零后端，CSV 不离开浏览器。

### 为什么是现在

当缺料事件发生，速度不是为了“更快做一张报表”，而是为了保鲜行动选项：提前三周催交、
提前两周安抚客户，与断线前三天再补救完全不同。传统中小厂常需几天跨部门拼 Excel，
本工具把第一次打击面推演压到 30 秒，并允许采购承诺一变就立即重算。

### 核心差异

市面排程产品大多停在报表或 ERP 集成。本作品把输出做成三级结构：

1. 缺料事件；
2. 打击面与可参数化 Playbook；
3. 可直接发给部门 agent 或负责人的执行指令。

行动空间有限反而是可信度优势：工具穷举通用选项、展示算账过程；机器不知道的测试成本、
罚款条款与现场良率空间由人显式输入，不让 AI 假装创造策略。

### 合成演示

内置工厂由程序生成：

- 24 个成品号、8 个二级模组、2–3 层 BOM；
- 多产品共用的电容、电阻、芯片与连接器；
- 库存、预留、两批到货和 24 张产线工单；
- 一键演示某电容首批到货延期两周的全链冲击。

所有公司名带“（合成）”；不存在任何原任职公司的真实或脱敏数据文件。

### 技术说明

- Vite + React 19 + TypeScript + Tailwind CSS；
- `@xyflow/react` 冲击传播图；
- CSS 轻量产线甘特 delta；
- TypeScript 纯函数执行多层 BOM 展开、循环引用防御、到货批次分配、缺口与延期计算；
- CSV 模糊列名匹配，宽容单位与日期解析；
- 浏览器 Clipboard / Blob 完成 prompt 复制与 JSON 导出；
- Vitest 覆盖多层共用件、循环引用、脏数据解析、改期重算和指令模板；
- 纯静态应用，无后端、数据库、账号、API key 或运行时 LLM。

### AI 参与度说明

本作品使用 AI Coding Agent 协助需求拆解、TypeScript 规则实现、React 交互、单元测试与文档。
产品定位、制造业行动空间、数据红线、技术裁决与最终验收由作者决定。提交材料将如实说明

### 当前限制

v0.1 是快速冲击推演器，不是精细有限产能排程器；不做需求预测、HR 排班、多工厂，也不向
ERP/MES 回写。导入结果仍需计划员、采购和现场负责人确认。行动回写后自动重算属于 9 月
旗舰开源版本 roadmap。

## 小红书笔记草稿

### 标题备选

1. 一颗电容晚到 14 天，工厂到底会停哪条线？
2. 我把“缺料开会”做成了一个 30 秒推演器
3. 雇不起 Palantir 的工厂，也该有自己的缺料作战室

### 正文

在工厂里，一颗几分钱的电容，真的可能打停几百万元的订单。

问题通常不是大家不知道怎么办。催供应商、挪料保单、安抚客户、找替代料、提良率——
这些选项每个人都会背。

难的是：  
要催回几天才来得及？  
同一颗料被 5 个产品抢，保谁的全局代价最小？  
哪些客户单可以滑，罚款是多少？  
替代料测试 12 天，但产线 8 天后就断，这个选项还活着吗？

所以我做了「断料雷达」。

把多层 BOM、库存、到货和周计划放进浏览器，一颗料的影响会一路展开到成品、工单、产线
和客户。改一个到货日期，全图即时重算；然后生成采购、产线、仓库、计划四张可以直接发给
人或 agent 的指令卡。

我刻意没有让 LLM 参与运行时计算。数量、日期、缺口和排序都是 TypeScript 确定性规则；
自然语言只是模板。零后端、零 key，CSV 不上传。

内置演示是程序生成的 24 个成品和 2–3 层 BOM，不含任何真实公司数据。黑客松只是它的
首发场，接下来我会把它养成一个面向中小制造企业的轻量开源工具。
